# NIRIKSHAN

NIRIKSHAN is a smart real-time inspection platform designed for GPS-based evidence capture, digital reporting, monitoring, and verification.

## Features

- GPS-based inspection
- Evidence capture
- Digital reporting
- Real-time monitoring
- Verification system
- Simple and user-friendly interface

This repository contains the source code and project files for NIRIKSHAN.
